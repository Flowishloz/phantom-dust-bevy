# UI de-clutter proposals (2026-10-09)

Laurence's UI direction is "modern comfort" plus **de-clutter the space** (DECISIONS.md 2026-10-09). The first item, the character bios on the character-select screen, is done (approved).

**Status (2026-10-09, Laurence's panel pick):** items 1-13 are **built** (FRONTEND.md "De-clutter wave", HUD.md). Items 14 and 15 are **built behind switches for an A/B pick** (`PD_HUD_SLIM_FOES=1`, `PD_HUD_SHARED_TIMER=1`; defaults unchanged). Before / after pairs and the two A/B sheets: `engine/shots/declutter/built/` (local). Notes on what was built where it differs from the wording below: item 1 keeps the keyboard line but shows it only while the keyboard is in use; item 7 keeps "PLAYER n" on the cards and puts the character names on the stats columns; item 10 reads "10 MIN (RULE)" (a plain "10 MIN" would look like the separate 10-minute choice).

**Picture sheets** (local only, they contain game art): `engine/shots/declutter/01_title.png` .. `13_pause_pad_lost.png`. Each sheet is a screenshot with numbered red boxes, and the numbers match the list below. Captured with the dev build on 2026-10-09 (`--open-screen`, `--menu-script`, `PD_TEST_OPTIONS_TAB`, `PD_TEST_PAD_LOST`, `--demo --near [--players 4]`).

Effort: S = text or visibility change in one file, M = a few files or new logic, L = layout rework.
