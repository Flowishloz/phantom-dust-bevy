# Combat core audit: hit reactions, knock-down, damage, health, Aura, Level, rounds vs the original (2026-09-30, cloud, read-only)

Document-and-code audit only: nothing was built or run, no game data and no Ghidra export in the cloud session. Left column = what `PROGRAM-RE.md` (PRE) / `FORMATS-SKILLS.md` (FS) / `MOVES.md` / `GAME.md` / `FOOTAGE.md` say; right = our code, read on 2026-09-30 (`combat.rs` = `engine/crates/pd_game/src/combat.rs`, `sim.rs`, `moves/effects.rs`, `main.rs`, `frontend/state.rs`). Nothing here is a new fact about the program; every "check on PC" is a question for Ghidra. Style follows `MOVEMENT-AUDIT.md`.

Units: the program ticks at 30 Hz, we tick at 60 Hz (`SIM_TICKS_PER_TABLE_TICK` = 2, `moves/mod.rs:33`). "sim t" = our 60 Hz ticks, "prog t" = program ticks. FOOTAGE.md has almost nothing on health, Aura, damage or reactions beyond "a knockdown/stagger is visible on a Blaster hit" and a ~1.36 s Psycho Knife recovery; every verdict below is therefore program-read vs code, not footage-checked.

Verdicts: MATCH = code follows the doc; ADDED BY US = rule in code the docs/program do not state; DIFFERS = code contradicts the doc; UNKNOWN = the docs mark it unread, or the doc is ambiguous.
