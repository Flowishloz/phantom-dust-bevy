Generated by `engine/re/skill_audit.py` (program side: `skill_audit_rules.py`; our side: the test-only probe `crates/pd_game/src/combat/skill_audit.rs`). Standing rule (Laurence, 2026-10-01): **no guessed values**. Every program value in this ledger is READ (program address / table field) or MEASURED (footage); anything else is shown as UNCONFIRMED and never counted as a match or a mismatch.

| Mark | Meaning |
|---|---|
| ✅ | match: ours equals the READ / MEASURED program value |
| ❌ | mismatch with a READ / MEASURED program value |
| ? | UNCONFIRMED: the program value is not settled and no recording could settle it |
| T | **needs take**: not settled from the program, but the move recorder (`engine/re/move_recorder.py`, MOVE-RECORDER.md) can measure it live on the original |
| … | not probed: a hole in this tool (a setup the arena cannot make, a family with no probe yet), not a finding |
| blank | nothing to compare for this skill in that column |

A column shows its worst cell; the detail list below names every cross.

### What a mark covers, and what it does not

A ✅ in a column means every value this tool reads for that column matched. It does **not** cover: the contact geometry of a Hole against a disc guard and the steering strength of Course / About Face shots in motion (the battery resolves the block / break / Pierce / ignore-list rules of `FUN_140271760`, the sent-back / Brush stun / Add effects, and the automatic Shelters, Orb and Amulet through an incoming attack, but not where a shot turns); the steering strength of Parabola / Fall / Crawl / Arc flights in motion (their constructor numbers and the shell homing are compared, the arc re-aim and crawl turn acceleration are not); rain-drop scatter, blast growth, mine triggers beyond fuse and radius; knock-down physics and hit-reaction clips beyond the chosen row; animation, effect and shader rendering (only the effect NUMBER per cast row and whether our export has it); sound timing and mixing (only which ids); camera, lock-on and movement. Those belong to the lanes that own them.
