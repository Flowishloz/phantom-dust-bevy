# Effects and sound audit: our playback vs the original (2026-09-30, cloud, read-only)

Document-and-code audit only: nothing was built or run (no game data, no cache, no Ghidra export in the cloud session). It compares `pd_game/src/{effects,fx,sfx}.rs` (plus `frontend/sound.rs`, `pd_formats/src/sound.rs`) with what `FORMATS-EFFECTS.md`, `FORMATS-AUDIO.md`, `VFX-AUDIT.md`, `CAPSULE-VISUALS.md` and `PROGRAM-RE.md` say the program does. Style follows `MOVEMENT-AUDIT.md`. Nothing here is a new finding about the program: a "check on PC" line is a question for Ghidra, `engine/re/` or footage. Line numbers are from the tree at audit time.

Verdicts: **MATCH** (code follows a doc-confirmed rule) / **ADDED BY US** (the program is not known to do it) / **DIFFERS** (docs say the program does otherwise) / **UNKNOWN** (docs do not say). Doc status marks carried over: ✅ program-read, ⚠️ inferred, ❓ unread.

Standing caveat (`FORMATS-AUDIO.md` line 5): **nobody has listened to any decoded sound**. Every sound-id mapping below is by numbers, cross-correlation or waveform images only. The only footage-confirmed sound ids are 242 (Laser cast), 243 (Slide Laser cast) and Psycho Knife's 501 impact (corr. 0.67, FORMATS-AUDIO s21 row).

## Headline list (most likely to explain "sounds and effects feel off")

1. **Cast sound and voice always come from the GROUND action row**, even for a mid-air cast (`sfx.rs:205`, `action_row(id, false)`; voice group `sfx.rs:225` prefers ground). The program reads the row it is casting from; the air row can differ (combat.rs test row 306 has `cast_sound: 528`, ground Laser 242). Section A1.
2. **s19 is played at cast start; the program plays it at the fire tick** (`FUN_1402626d0`). Section A3. Affects the 17 [Rain]/[Fall] skills with the 618 whistle, and Ki shots with 313/314.
3. **Reaction-row sound (w3) and reaction-row effect are loaded but never used** (`main.rs:468` loads `sound`/`effect`; grep finds no reader). Program plays w3 "with the hit effect" (`FUN_140258690` -> `FUN_140259310`). Section A4/B4.
4. **Sounds the docs name that we never play**: hit sound 6/7 (impact code 2), blast sound 99, guard-broken sound 14, capsule-appear 0x55 (85), environment crystal 0x5d (93), jump-zone hum 79. Section A5.
5. **No slot 5 (barrier break) effect at all**: `SLOT_BLOCK` (4) only; nothing plays slot 5 on `broken: true` (`fx.rs:150-158`). Program: code 10 = slot 5 + sound 14. Section B4.
6. **Blend is additive for everything except translucent puffs (alpha-kill), solid shells (opaque) and hidden distortion**; per-draw blend state was never read (`FORMATS-EFFECTS.md` "Open"). Section C.
7. **Every effect and sound is unheard or uncompared except a short list** (Section F). Footage exists only for Laser, Slide Laser, Blaster (partial), Psycho Knife, Jump, Lock-On.

### A-x. Sound ids with no reference from code or skills

- `common` has 553 ids in 0-634. The skill table references only 301-354 (s13: **not sounds**), 501-527 (s21), 601-617 (s20), 313/314/618 (s19), plus row w3 cast ids (mostly row + 200: 201-~299, 528).
- **Ids 44-300 and 355-500 are "not referenced by the skill table" and unlabelled** (FORMATS-AUDIO line 81). Ids the PROGRAM-RE text **names** inside or near that range, none of which we play: 79 (jump-zone loop), 85 = 0x55 (capsule appears), 93 = 0x5d (environment crystal set), 99 (blast); below 44: 6, 7 (hit), 14 (guard broken), 17 (st06 break). Menu ids 60/116/154 are our own picks from that range.
- Action-row cast sounds (w3) reach up to ~299 (row + 200) and 528 (air row), so most of 201-299 **are** used, via rows; the genuinely unreferenced set is therefore mainly 44-200 and 355-500. **Check on PC**: dump the set of ids referenced by any `FUN_` sound-player call site (the function that takes (bank, id)); the diff against `common`'s 553 ids is the list to label. No such list exists in the docs.
- The sound player's bank argument is always 0 in the calls read; other banks (BattleVo, MapSE, BossSE) are reached some other way: MapSE (stage ambience) is **not played at all** by `pd_game`, nor DSP_* reverb settings (❓ in FORMATS-AUDIO).
